# Alert budget (synthetic, real decision path)

Generated by `uv run python -m research.alert_budget.run_alert_budget` at commit `fda5496` on 2026-10-08. Code state: pre-fix (policy 1.0.0, no context layer).

Routine = known vendor, registered account, in-pattern amount (floor PASS), with 1-3 realistic benign AP messages (footers, bank OTP SMS, IT notices, Diwali vouchers, GST/TDS mails, WhatsApp chatter). Attack = one case per held-out attacker ask (payee change, new payee, credential/remote-access request) + 12 de-minimis splitting cases. Signals come only from the real ask extractor run on the text; e-mail header checks (T03/T04) are not built, so they contribute nothing here.

Every routine case carries at least one message and the benign set is deliberately rich in footers and bank SMS, so routine rates are an upper bound for a real payment run. 95% Wilson intervals in brackets. **Quote the `test` split**: the context layer was designed while reading dev-split texts only.
