# Design history

How we got to the current design. Read in order if you want the "why".

1. `00_RESEARCH_NOTES.md` — verified research notes (papers, datasets, India rules, tools).
2. `01_CRITIQUE.md` — an independent critic's 27 ranked flaws of design v2.
3. `02_APPROACH_V3.md` — the improved v3 approach that fixes them. `docs/ARCHITECTURE.md` and the task specs are built from this.

Decisions made while building the repo (where v3 was refined) are in `docs/DECISIONS.md`.
