# M4 Design Note — Multimedia Provenance & Source Attribution

## 1. Objective
Build `src/satyapan/forensics/provenance.py` to establish multimedia origin, metadata integrity, C2PA Content Credentials status, and compression-fingerprint source attribution (`camera_original` vs `social_messaging_reencode` vs `editing_software_resave`).

## 2. Three Provenance Engines
### 2.1 EXIF / XMP / Container Metadata Consistency (`extract_and_verify_metadata`)
Extracts TIFF/EXIF IFDs (including SubIFD `0x8769`, GPS IFD `0x8825`, and IFD1 thumbnail `0x0201`/`0x0202`), XMP XML packets, and PNG text chunks (`parameters`, `Software`, `prompt`), then executes 5 deterministic checks:
1. **Timestamp Chronology**: Compares `DateTimeOriginal`, `DateTimeDigitized`, `DateTime`, and XMP `CreateDate`/`ModifyDate`. Flags chronological inversions (`DateTimeOriginal > DateTime`).
2. **Software & Generative AI Signatures**: Detects photo/video/audio editors (Photoshop, GIMP, FFmpeg, Audacity) and generative AI parameter blocks (Stable Diffusion, ComfyUI, Midjourney, DALL-E, Firefly).
3. **GPS Plausibility**: Validates latitude/longitude bounds, flags Null Island `(0.0, 0.0)`, and checks GPS date against capture timestamp.
4. **Embedded Thumbnail vs Main Image**: Extracts the APP1 IFD1 JPEG thumbnail and compares aspect ratio and pixel correlation/MAE against the downscaled main image. Catches cropped or spliced photos whose original thumbnail was not updated by the editor, rendering `thumbnail_comparison.png`.
5. **Camera Make/Model vs Container**: Flags contradictory combinations (e.g., camera EXIF injected into a lossless PNG or non-standard aspect crop).

### 2.2 C2PA Content Credentials Verifier (`verify_c2pa_credentials`)
- Uses `c2pa-python` if installed; in our air-gapped `.venv` (recorded in `BLOCKERS.md`), runs a built-in pure-Python JUMBF (`c2pa` UUID `63327061-0011-0010-8000-00aa00389b71` / JPEG APP11 / PNG `caBX`) manifest parser and Ed25519 + SHA-256 hard-binding verifier.
- Reports `valid_c2pa_manifest`, `tampered_c2pa_hash_mismatch`, `invalid_c2pa_signature`, or `no_c2pa_manifest`, and surfaces `digitalSourceType` (e.g., `trainedAlgorithmicMedia`).

### 2.3 Compression-Fingerprint Source Attribution (`attribute_compression_source`)
- Extracts quantization-table energy, low/high-frequency step ratios, chroma subsampling (`4:4:4`, `4:2:2`, `4:2:0`), container format, resolution profile, and metadata survival to attribute images to:
  1. `camera_original`
  2. `social_messaging_reencode` (WhatsApp/Instagram-style Q60–Q82 4:2:0 + stripped EXIF)
  3. `editing_software_resave`

## 3. Evaluation Protocol
- Evaluated on a seeded 150-image benchmark (`research/forensics/eval_m4_provenance.py`, `SEED = 20261104`) generated by re-encoding open/synthetic images across the 3 provenance channels plus metadata-tampered and C2PA-signed test cases.
