# M5 Design Note — Explainable Multimedia Forensic Analysis Dashboard

## 1. Objective
Build the unified forensic case pipeline (`src/satyapan/forensics/pipeline.py`) and an offline, publication-grade **Multimedia Forensic Analysis Workstation** (`src/satyapan/api/routes_forensics.py` at `/forensics` and `/api/forensics/*`) tailored for investigating agencies and forensic laboratories.

## 2. Case Pipeline (`src/satyapan/forensics/pipeline.py`)
For each sealed evidence item in a `ForensicLocker` case:
1. Checks out an isolated working copy (`locker.checkout_working_copy(evidence_id)`).
2. Runs modality-appropriate forensic engines:
   - **Image**: M2 (`analyze_image_deepfake`), M3 (`analyze_image_tampering`), M4 (`analyze_provenance`);
   - **Video**: M2 (`analyze_video_deepfake`), M3 (`analyze_video_tampering`), M4 (`analyze_provenance`);
   - **Audio**: M2 (`analyze_audio_deepfake`), M3 (`analyze_audio_tampering`);
   - **Document/PDF**: M4 (`analyze_provenance`) + Satyapan document metadata/edit checks.
3. Synthesizes an item-level non-absolutist forensic summary (`overall_finding`, `overall_confidence`, `overall_statement`, `combined_why`, `combined_limitations`), logs a signed `"analyze"` custody entry, merges all metadata/custody/anomaly timestamps onto a **chronological case timeline**, and persists `case_dir/analysis.json`.

## 3. Dashboard Views & API (`/forensics` & `/api/forensics/*`)
- `GET /forensics`: Self-contained offline single-page investigator workstation (zero external fonts, scripts, or CDN calls).
- `GET /api/forensics/cases`: Lists forensic cases; `POST /api/forensics/cases` creates a new case; `POST /api/forensics/demo-case` seeds and analyzes a multi-modal demonstration case (`case_forensic_demo_01`).
- `GET /api/forensics/cases/{case_id}`: Full case view including locker integrity banner (`PASSED` / `TAMPERED`), files, per-check findings + confidence + technical `"why"` + visual artifact URLs, chronological timeline, Ed25519-signed custody log + RFC 6962 Merkle proofs, and the **"Limits of This Analysis"** panel.
- `POST /api/forensics/cases/{case_id}/intake`: Multipart file intake $\to$ SHA-256 seal (`0o444`) $\to$ working copy $\to$ full M2+M3+M4 analysis.
- `GET /api/forensics/cases/{case_id}/artifacts/{evidence_id}/{name}`: Serves generated heatmaps and spectrograms (`ela_heatmap.png`, `copy_move_heatmap.png`, `noise_residual_heatmap.png`, `tamper_composite.png`, `deepfake_spectrum.png`, `video_frame_scores.png`, `video_tamper_timeline.png`, `audio_splice_spectrogram.png`, `thumbnail_comparison.png`).
- `POST /api/forensics/cases/{case_id}/tamper-sim/{evidence_id}` & `.../tamper-restore/{evidence_id}`: Live 1-bit tamper simulation & restoration on sealed copies.
